🎨 Palette: [UX 개선] 파일 용량 입력 폼에서 값을 비웠을 때 명시적인 에러 메시지 제공

💡 What
- 단일 및 일괄 업로드 폼의 대상 바이트(`target_bytes`) 필드와 파일 입력 폼을 비웠을 때, 기존의 단순 상태 초기화(empty string) 대신 `This field is required.`라는 명시적인 에러 메시지와 빨간색(`style.color = '#dc3545'`) 시각적 피드백을 추가했습니다.
- JavaScript의 `setCustomValidity`와 더불어 `aria-invalid='true'` 속성을 동시에 부여하도록 업데이트했습니다.

🎯 Why
- 기존에는 사용자가 필수 입력값을 지웠을 때 시각적인 피드백이 사라지고 스크린 리더에도 유효하지 않은 상태임을 전달하지 못하여, 사용자가 잘못된 동작임을 즉각적으로 인지하기 어려웠습니다.
- 이 변경을 통해 시각적 사용자 및 스크린 리더 사용자 모두 필수 입력 필드가 비워졌다는 명확한 경고를 받게 되어 접근성(Accessibility)과 전반적인 UX가 향상됩니다.

📸 Before/After
- **Before:** 값을 지우면 에러 메시지 텍스트가 단순히 지워지고, `aria-invalid` 상태가 제거됨.
- **After:** 값을 지우면 빨간 텍스트로 "This field is required." 표시, `setCustomValidity` 설정, `aria-invalid='true'` 설정됨.

♿ Accessibility
- `aria-invalid='true'`를 명시적으로 설정하여 스크린 리더 사용자가 폼 필드의 오류 상태를 정확히 인지할 수 있도록 하였습니다.
