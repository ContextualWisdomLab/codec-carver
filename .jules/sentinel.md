## 2025-02-14 - Fix DoS via Non-ASCII Header Parsing in hmac.compare_digest
**Vulnerability:** A Denial of Service (DoS) vulnerability existed in the API key verification logic. Passing a non-ASCII character in the `X-API-Key` HTTP header caused `hmac.compare_digest` to raise an unhandled `TypeError`, resulting in a 500 Internal Server Error.
**Learning:** `hmac.compare_digest` in Python strictly requires ASCII or UTF-8 encoded bytes when comparing values, and fails on Unicode strings containing non-ASCII characters. Frameworks like FastAPI/Starlette do not automatically sanitize headers to pure ASCII if not requested.
**Prevention:** Always explicitly encode string inputs (especially untrusted HTTP headers) to `utf-8` bytes (e.g., `.encode("utf-8", "replace")`) before passing them to low-level cryptographic functions like `hmac.compare_digest` to prevent unhandled type errors.
