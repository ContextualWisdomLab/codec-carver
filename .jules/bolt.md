## 2024-05-18 - Set 교집합 최적화
**Learning:** 루프 내에서 `&` 연산자를 사용하여 세트 교집합을 구하면 매 반복마다 새로운 세트 객체가 할당되어 오버헤드가 발생함. 파이썬의 `set.intersection_update()`는 기존 세트를 제자리(in-place)에서 수정하므로 중간 객체 생성 비용을 제거하고 핫루프 내에서 실행 속도를 크게 개선할 수 있음.
**Action:** 교집합 결과를 계속해서 하나의 세트 변수에 누적 갱신해야 할 때는 `&` 대신 `.intersection_update()` 메서드를 사용하도록 적용함.
