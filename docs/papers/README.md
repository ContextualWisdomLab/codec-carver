# Reference papers

- **`fuzzing-art-science-engineering-survey.pdf`** —
  V.-T. Manès, H. Han, C. Han, S. K. Cha, M. Egele, E. J. Schwartz, M. Woo,
  *"The Art, Science, and Engineering of Fuzzing: A Survey"*, IEEE TSE 2019
  ([arXiv:1812.00140](https://arxiv.org/abs/1812.00140)).

  Background for the coverage-guided fuzzing approach used in `fuzz/`: the
  Atheris harnesses are libFuzzer-style greybox fuzzers as characterised in
  Section 3 of the survey.

- **Codd (1972) / ISO/IEC 11179-1:2023 / ISO 8601-1:2019** — cited in
  [`docs/doctoring/conversion-jobs-schema.md`](../doctoring/conversion-jobs-schema.md).
  PDFs are not copied here; the ISO texts are not freely redistributable.
  Use those citations when changing `conversion_jobs` columns or the
  legacy `jobs` copy.
